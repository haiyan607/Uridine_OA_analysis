# Processed data

This directory is used for intermediate and processed analysis objects generated by the R scripts.

Typical files include:

```text
GSE220243_26samples_datalist_raw.rds
GSE220243_26samples_datalist_after_QC.rds
GSE220243_merged_after_QC.rds
GSE220243_QC_normalized.rds
GSE220243_QC_normalized_hvg_scaled.rds
GSE220243_QC_normalized_hvg_scaled_harmony_umap.rds
```

These files may be large and are therefore excluded from GitHub by `.gitignore`.

## How to generate the files

Run the single-cell scripts from the repository root in the following order:

```text
code/01_single_cell/01_create_single_sample_seurat_objects.R
code/01_single_cell/02_quality_control_and_normalization.R
code/01_single_cell/03_run_pca_harmony_umap.R
```

The resulting processed Seurat objects will be written to this directory.

## Reproducibility

Processed objects are not required to be stored in the repository when they can be regenerated from the public raw dataset and the provided scripts.

Small processed tables that are useful for verification should be saved in:

```text
results/tables/
```

Selected figures should be saved in:

```text
results/figures/
```
